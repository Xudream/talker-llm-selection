# 尺子1 接入清单（公开集）

> 目标：把五个公开集跑成一张可比的表，用于**淘汰**与**摸高**，不用于定选。
> 原则：**能直接用官方 harness 的，绝不自己重写判分**；我们的脚本只做抽样与格式转换。

---

## 1. 五个集与职责

| 集 | 仓库 | 覆盖 | 我们怎么用 | 抽样 |
|---|---|---|---|---|
| **BFCL v4** | `github.com/ShishirPatil/gorilla`（`berkeley-function-call-leaderboard/`） | 单轮 AST、并行、多轮、幻觉、Latency | 主淘汰线 | 5 个文件 × 150 ≈ 600（另有 150 幻觉） |
| **τ²-bench** | `github.com/sierra-research/tau2-bench` | 多轮闭环 + 双控（用户/系统） | 两步闭环保守估计 | retail / airline / telecom 各 15 任务 |
| **ACEBench** | `github.com/chenchen0103/ACEBench`（arXiv:2501.12851） | 中文工具调用 | 中文说法对照 | 300 |
| **IFEval** | `github.com/google-research/google-research/tree/master/instruction_following_eval` | 25 类可验证约束 | 格式/长度底线 | 全量 541（便宜） |
| **HaluEval-zh / CMMLU** | HuggingFace 公开集 | 幻觉倾向 / 中文常识 | 反向筛除 + 闲聊兜底 | 各 200 |

合计约 1,750 次调用/模型；云 API 成本 < ¥60/模型【估算】。

## 2. BFCL v4（主淘汰线）

### 2.1 数据格式先搞清楚

- 数据文件是 **JSONL**（每行一个对象），不是 JSON 数组——用 `json.load` 会报 `Extra data`
- 每个对象：`{id, question: [[{role,content}...]], function: [{name,description,parameters}]}`
- 答案在 `data/possible_answer/` 下，形如 `[{func_name: {arg: [可接受值1, 可接受值2]}}]`
- **注意**：gold 是"可接受值集合"，不是单值 → 我们的 `score.py` 只能做快比，正式分必须用官方 AST

### 2.2 抽样 + 转格式（本仓库脚本）

```bash
# 需要代理时带上 HTTPS_PROXY
HTTPS_PROXY=http://127.0.0.1:7890 python3 tools/fetch_public_sets.py \
  --set bfcl_v4 --per-file 150 --out tasksets/public_bfcl_v4.jsonl
```

产出字段（与尺子2 同构，可直接喂 `run_model.py`）：

| 字段 | 说明 |
|---|---|
| `axis` | A1（单轮）/ A2（并行）/ A4（幻觉irrelevance）/ D（多轮） |
| `official_id` | 官方 id，用于把官方分数按 id 回填 |
| `gold.official_answer` | 官方可接受值集合（原样保留） |
| `score_by` | `official`（用 AST 判）/ `local`（幻觉切面，本地可判） |

### 2.3 官方判分（正式分数）

```bash
git clone https://github.com/ShishirPatil/gorilla.git
cd gorilla/berkeley-function-call-leaderboard
pip install -e .

# 指向自家端点（OpenAI 兼容）
bfcl generate --model <model-name> \
  --register-config path/to/config.json \
  --result-dir ./result
bfcl evaluate --model <model-name> --test-category simple_python,multiple,parallel,irrelevance,multi_turn_base
```

`config.json` 模板：

```json
{"<model-name>": {"model_name": "<served-model-name>",
                  "base_url": "http://127.0.0.1:8000/v1",
                  "api_key": "dummy",
                  "temperature": 0.0}}
```

产出：`result/<model>/BFCL_v4_<category>_score.json`，其中含 `accuracy`、`correct_count`、`total_count`。

### 2.4 门槛

| 类别 | 门槛 |
|---|---:|
| 单轮（simple + multiple） | ≥ 75% |
| 多轮 base | ≥ 55% |
| irrelevance（该拒未拒） | ≤ 15% |
| 并行（如果 Talker 用到） | ≥ 65% |

## 3. τ²-bench（两步闭环）

```bash
git clone https://github.com/sierra-research/tau2-bench && cd tau2-bench
pip install -e .
# 每域只跑 15 个任务
tau2 run --domain retail  --agent-llm <model> --user-llm <model> --num-tasks 15
tau2 run --domain airline --agent-llm <model> --user-llm <model> --num-tasks 15
tau2 run --domain telecom --agent-llm <model> --user-llm <model> --num-tasks 15
```

判分用官方 simulator 的打分（`reward`/`success`），**不要用我们的 score.py**。
门槛：三域平均闭环成功率 ≥ 40%（公开集是客服域，低于业务域，门槛放低）。

## 5. IFEval（约束遵循）

```bash

cd google-research/instruction_following_eval
python3 instruction_following_eval/run_eval.py \
  --input_data=instruction_following_eval/input_data.jsonl \
  --input_response_data=<our_responses.jsonl> \
  --output_dir=./out
```

- 541 条全跑；产出 `strict` 与 `loose` 两个准确率
- 门槛：strict ≥ 80%

## 8. 执行顺序（一个模型约 3–4 小时，含装环境）

1. `fetch_public_sets.py` 抽 BFCL → `run_model.py` 跑本地快比（30 分钟，先看有没有格式崩）
2. 装 BFCL harness → 跑正式 AST（1 小时）
3. τ² / ACEBench / IFEval（可选并行，1.5 小时）
4. 填结果表 → 决定进不进尺子2

## 9. 三个坑

| 坑 | 表现 | 处理 |
|---|---|---|
| 把 JSONL 当 JSON 读 | `Extra data: line 2 column 1` | 逐行 `json.loads`（脚本已处理） |
| 拿 gold 单值比对 | 全错，但模型其实对 | BFCL gold 是"可接受值集合"，必须走官方 AST |
| 用我们的 score.py 出正式分 | 分数偏低且不可对外 | 正式分只认官方 harness；我们的脚本只做抽样与冒烟 |
